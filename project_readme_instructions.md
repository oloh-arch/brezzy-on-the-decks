# BREZZY ON THE DECKS - Official Web Application

Official brand platform and DJ mix showcase site for **Brezzy On The Decks**, a top Kenyan DJ and mix creator based in Nairobi.

## Features
- Fully responsive modern dark theme with Neon Green accents.
- Embedded YouTube Player modal for streaming mixes.
- Dynamic WhatsApp event booking pre-filled link generator.
- Comprehensive Google SEO metadata & structured JSON-LD schema for high rankings on search terms like "Brezzy On The Decks Kenya", "Kenyan DJ Mixes", and "Gengetone DJ Mixes".
- 100% compatible with GitHub Pages hosting.

## Files Included
- `index.html` — Main website HTML5 markup with Tailwind CDN & inline scripts.
- `style.css` — Modern styling tokens & custom visual glows.
- `script.js` — Client-side interaction logic.
- `sitemap.xml` — Google Search Console indexing sitemap.
- `robots.txt` — Search engine crawling instructions.
